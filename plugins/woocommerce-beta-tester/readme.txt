Run prerelease and development versions of WooCommerce, plus developer test tools. For testing sites only.

== Description ==

WooCommerce Beta Tester lets you try upcoming versions of WooCommerce before they are released. Use it on development and staging sites only, not on production sites.

Features:

* Choose an update channel (beta, release candidate or stable) and switch to any released WooCommerce version.
* Install and activate builds of WooCommerce pull requests and trunk with Live Branches.
* Use the WCA Test Helper (Tools > WCA Test Helper) for developer tools such as options, feature flags and remote logging.

Find the settings under Plugins > WC Beta Tester.
